# terraform-provider-weka

Terraform provider for configuring a running Weka cluster through its REST API.

Private for now. Intended to be published later, so keep cluster-specific names, credentials, and endpoints out of this repo.

## Scope

A Weka Kubernetes operator owns the cluster: backends, clients, drives, CSI, and whether protocol services exist.

This provider owns configuration inside a cluster that is already up:

- filesystems and filesystem groups
- quotas and snapshot policies
- object-store buckets
- S3 buckets and policies
- NFS permissions and SMB shares
- organizations, users, and login policy

## Layout

- `internal/wekaapi/` — Go client generated from a pinned Weka 4.4 OpenAPI spec, plus a wrapper for login and calls that finish in the background.
- `internal/provider/` — hand-written resources on top of that client. `weka_filesystem_group` is the first.
- `docs/` — generated by `go generate ./...`.

Contributor conventions are in [AGENTS.md](AGENTS.md).

The provider address is `registry.terraform.io/absci/weka`.

## Using an unpublished build

Build the binary and point Terraform at it with [`dev_overrides`](https://developer.hashicorp.com/terraform/cli/config/config-file#development-overrides-for-provider-developers),
so `terraform init` is not needed and no Terraform Registry entry has to exist yet:

```shell
go build -o ~/go/bin/terraform-provider-weka .
```

```hcl
# ~/.terraformrc
provider_installation {
  dev_overrides {
    "registry.terraform.io/absci/weka" = "/Users/you/go/bin"
  }
  direct {}
}
```

Terraform warns on every plan/apply while an override is active. That is expected.

## Publishing

Development stays on this private GitLab project. Do not publish until all of these are done. `registry.terraform.io` only detects a public GitHub repository named `terraform-provider-weka`.

- [ ] Public GitHub repository `terraform-provider-weka`, mirrored from this project.
- [ ] `.goreleaser.yml` and `terraform-registry-manifest.json` (protocol `6.0`).
- [ ] GPG signing key registered with the Terraform Registry.
- [ ] `absci` namespace claimed on the registry.
- [ ] Finalized GitHub release tagged `vX.Y.Z`. The tag must not also be a branch name. The release contains the per-OS zips, the manifest, `SHA256SUMS`, and a GPG signature of the checksums.
